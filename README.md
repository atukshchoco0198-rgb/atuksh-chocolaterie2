## ⚡ Real-Time Cloud Sync (New!)

Your website now includes a dual-engine real-time synchronization system:

### 1. Instant Tab-to-Tab Broadcast (Zero Config!)
- Works out of the box using browser `BroadcastChannel`.
- Any edit you make in the Admin Panel instantly reflects across every open window/tab on your device in real time without refreshing.

### 2. Multi-Device Cloud Sync (Firebase Firestore)
- Inside the Admin Panel under **"⚡ Real-Time Cloud Sync"**:
  - Paste your free Firebase configuration (`apiKey`, `projectId`, `appId`).
  - Click **"Connect Real-Time Cloud Sync"**.
  - Click **"Push Local Data to Cloud"**.
- Once connected, whenever you add or edit chocolates, modify prices, publish reviews, or change the brand logo on your phone or laptop, every customer looking at the website on any device sees the updates **live in milliseconds without refreshing the page!**

## 📦 Customer Orders Log (New!)

Every time a customer places an order via the basket or sends a custom gift hamper inquiry:
- The order is automatically logged in the Admin Panel under **"Recent Orders"**.
- View: Order ID, Timestamp, Customer Name, Delivery Address (Panchkula / Tricity / other), Items list, and Total Payable.
- Update order statuses: `New` → `Preparing` → `Dispatched` → `Delivered`.
- One-click **"Chat"** button to message the customer directly on WhatsApp regarding their order.
- One-click **"Export CSV"** button to download your orders list for bookkeeping.
